# School Manager (تعلیمی ادارہ منیجر)

Offline Urdu school record app: students, attendance, fees, exam results, backup/restore.
All data stays on the phone. No account, no server, no ads, no analytics.

**Stack:** plain HTML/CSS/JS in `www/`, wrapped with Capacitor 8 (Android target SDK 36, Node 22, JDK 21).
The `android/` folder is generated by the workflow, so it is not stored in this repo.

## Before you build: change these (important)
1. `capacitor.config.json` -> set your real `appId` (package ID), e.g. `com.yourname.schoolmanager`.
   It is currently the placeholder `com.changeme.schoolmanager`. **The ID cannot be changed after you publish on Google Play.**
2. `docs/PRIVACY_POLICY.md` -> fill in the developer name and contact email, then publish it as a public HTTPS web page.

## Upload to GitHub
1. Create a new empty repository on github.com (private is fine).
2. Extract the ZIP. Upload everything inside the `school-manager` folder, including the hidden `.github` folder.
   (On a phone/browser: "Add file > Upload files". If `.github` does not upload, create the file
   `.github/workflows/android-build.yml` manually and paste its content.)
3. The build starts automatically on every push to `main`. You can also open **Actions > Android Build > Run workflow**.

## Get the APK and AAB
Open the finished run in **Actions** and download the artifact at the bottom:
- Without signing secrets: `school-manager-unsigned-and-debug` containing
  `app-debug.apk` (install and test on a phone), `app-release-unsigned.apk`, `app-release.aab` (unsigned, not uploadable).
- With signing secrets: `school-manager-release-signed` containing `app-release-signed.apk` and `app-release-signed.aab`.
- `build-reports` contains the lint report and logs.

APK = file you install directly on a phone. AAB = the format you upload to Google Play.

## Signing (for Play Store)
See `docs/SIGNING_GUIDE.md`. Secrets needed: `KEYSTORE_BASE64`, `KEY_ALIAS`, `KEYSTORE_PASSWORD`, `KEY_PASSWORD`.

## Update the app later
Edit `www/index.html`, raise `androidVersionCode` (+1) and `version` in `package.json`, push to `main`.

## Using it for different institutions
- Each institution opens the app, taps Home > "ادارے کا نام اور لوگو", and enters its own name and logo. They show in the app header. They are saved with the backup.
- The phone's launcher icon and app name are fixed per build. For a separate Play Store listing per institution, copy the repo, change `appId` and `appName` in `capacitor.config.json`, and replace the images in `assets/`.

## Notes
- Data is stored in the app's local storage. Clearing app data or uninstalling deletes it.
  Use "Backup / Restore" on the Home tab regularly and keep the text somewhere safe.
- No password lock yet, no report-card printing yet, no multi-device sync.
- Dependency versions use `^8` ranges (no lockfile), so a newer 8.x may be picked on later builds.

See `docs/` for the privacy policy, Data Safety notes, permissions and release checklist.
