# Release checklist
Code side
- [ ] Real `appId` set in `capacitor.config.json` (not `com.changeme...`)
- [ ] `androidVersionCode` raised for every upload
- [ ] Workflow green; signed APK/AAB artifacts present
- [ ] APK tested on a real phone: add student, attendance, fee, result, backup/restore, Urdu text display, back button
Google Play Console (you must do these)
- [ ] Developer account and app created with the same package ID
- [ ] Privacy policy published on public HTTPS page and URL entered
- [ ] Data safety form, Ads declaration (No ads), Content rating, Target audience, App access declarations
- [ ] Store listing: Urdu/English title, description, screenshots, 512x512 icon, 1024x500 feature graphic
- [ ] Upload signed AAB to internal testing first
- [ ] Check current Google Play target API and testing requirements for new personal accounts on the release date
